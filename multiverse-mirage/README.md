# Multiverse Mirage (Angular Edition)

This directory contains the Angular implementation for the Multiverse Mirage app.

## Quick Start

1. **Install dependencies**  
   ```
   cd multiverse-mirage
   npm install
   ```

2. **Run the app**  
   ```
   npm start
   ```

   The app will be served at [http://localhost:4200](http://localhost:4200)

## Structure

- All source code in `src/app/`
- All Angular configuration in this folder

## Note

If you see errors about `package.json not found` in `multiverse_mirage/`, update your CI/build process to point to this directory (`multiverse-mirage/`) ONLY.
